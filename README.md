# Смена — прототип контроля состояния водителя

Прототип интерфейса для проекта 26-АУ-1: главная страница, локальный предпросмотр камеры, обнаружение закрытых глаз и полной темноты, а также кабинет работников с уведомлениями и журналом событий.

## Запуск

Откройте папку проекта в VS Code и запустите `index.html` через расширение Live Server либо другой локальный веб-сервер. Доступ к камере браузеры обычно разрешают только по HTTPS или с `localhost`; открытие файла напрямую может не поддерживаться.

Нажмите **«Подключить камеру»** и подтвердите разрешение в браузере. Чтобы завершить мониторинг, нажмите **«Отключить камеру»**.

## Мониторинг и история

- MediaPipe Face Landmarker ищет лицо и вычисляет закрытие обоих глаз по ключевым точкам: предупреждение появляется, если глаза закрыты дольше 3 секунд.
- Освещённость измеряется по яркости видеокадра: предупреждение о почти полностью чёрном кадре появляется после более чем 5 секунд. Порог яркости учитывает шум и усиление камеры при слабом свете.
- Активное предупреждение показывается поверх предпросмотра и в кабинете работников; статус контроля и текущая яркость доступны в кабинете.
- Оповещения видны в разделе **«Работникам»**, записи сохраняются в истории браузера на этом устройстве (до 200 событий).
- Видео и распознавание остаются в браузере. При первом анализе загружаются библиотека MediaPipe с jsDelivr и модель с Google Storage; для этого нужно подключение к интернету.
- Доступ к камере всё равно запрашивается только по нажатию кнопки. Видеопоток завершается при отключении камеры или закрытии страницы.
- Это учебный прототип: возможны ошибки распознавания, он не является сертифицированной системой безопасности и не должен заменять наблюдение человека. Локальная история не является общей историей для сотрудников и не синхронизируется между компьютерами.
